# МебельМастер — сайт ремонта корпусной мебели

Готовый статический сайт:
- index.html
- style.css
- script.js
- assets/ — папка для будущих фотографий

## Что нужно заменить перед публикацией
1. Телефон +998 90 000 00 00.
2. Telegram-ссылку https://t.me/ и @mebeltop.
3. Название "МебельМастер", если выберем другое.
4. Цены.
5. Заглушки фотографий на реальные фотографии работ.
6. При необходимости добавить реальную карту.

Сайт адаптирован под мобильные телефоны и ПК.
